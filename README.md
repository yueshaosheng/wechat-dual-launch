# 微信双开

`WeChat-Dual-Launch.command` 用于在 macOS 上从已安装的微信制作或重建第二个应用副本。一个脚本提供中英文界面，启动时输入 `1` 选择中文（直接回车也是中文），输入 `2` 选择 English；每次运行都可以重新选择。

## 使用方法

1. 确认原版微信安装在 `/Applications/WeChat.app`，重要聊天记录已备份。
2. 双击 `WeChat-Dual-Launch.command`，选择语言。
3. 检查显示的微信版本和副本状态，输入 `y` 并回车开始，其他输入取消。
4. 等待构建、签名和运行检查完成，在第二个微信中自行登录。
5. 确认账号及聊天记录正常后，再自行清理废纸篓中的旧应用副本。

无需事先删除已有的 `WeChat2.app`。脚本需要当前账户能写入“应用程序”目录，并拒绝以 `sudo` 运行。若双击无法执行，可在终端输入 `zsh `（末尾有空格），拖入脚本文件，再按回车。

## 脚本执行步骤

开始构建前，检查原版应用是否存在、目录写入权限和原版代码签名。

1. 在 `/Applications` 下创建独立的临时构建目录。
2. 用 `ditto` 复制当前安装的原版微信。
3. 用 `PlistBuddy` 将副本的 `CFBundleIdentifier` 改为 `com.tencent.xinWeChat2`。
4. 用 `codesign --force --deep --sign -` 对副本重签名。
5. 用 `codesign --verify --deep --strict` 验证副本；通过后请求正在运行的微信 2 正常退出。约 10 秒后仍未退出则停止，请手动退出再运行。随后将旧副本移入废纸篓，并安装新副本到 `/Applications/WeChat2.app`。
6. 打开原版和副本，等待 8 秒，检查两条应用路径对应的主进程，并显示手动换图标步骤。

进程检查只说明检查时两个程序在运行，不代表登录、消息收发及全部功能均验证通过。

## 双开原理

复制应用提供了第二份程序；修改 Bundle ID 改变了副本的应用标识，使其有机会与原版并行运行。修改应用内容会破坏原始签名，因此需要重新签名才能运行修改后的副本。

`--sign -` 使用 ad-hoc 临时签名，不包含腾讯的开发者身份，也不等同于 Apple 公证或系统信任。`--deep` 用于递归处理工具识别的嵌套代码；此处是针对本机副本的实用方案，不是通用的应用发行签名流程。签名验证通过也不保证 Gatekeeper 放行或微信功能完整。

本机此前在微信 4.1.13 上观察到两个主进程同时运行，以及副本创建了独立数据目录。其他版本可能改变单实例检查或数据路径，不能保证一直有效。此前并未对 `cp -R` 和 `ditto` 做严格对照测试，因此不能断定复制工具就是旧方法失效的原因。

## 数据、更新与恢复

- 原版应用不被修改，脚本从当前安装的版本复制，不下载微信或自动升级原版。
- 脚本不删除或复制聊天数据。此前观察到的第二个微信数据目录为 `~/Library/Containers/com.tencent.xinWeChat2`；原版为 `~/Library/Containers/com.tencent.xinWeChat`。
- 保持副本 Bundle ID 不变有助于继续使用既有数据，但不保证未来版本的数据迁移兼容性。
- 旧应用副本保存为 `~/.Trash/WeChat2-backup-时间戳.app`。这是程序备份，**不是聊天记录备份**。
- 构建或签名校验失败发生在替换前，旧副本仍保留。安装移动失败时会尝试恢复旧副本；启动检查失败不会自动回滚。
- 如需恢复，先退出微信 2，将失败的新应用移到废纸篓，再将备份移回“应用程序”并重命名为 `WeChat2.app`。不要删除数据目录。新版运行后若已迁移数据，旧版未必兼容。
- 原版升级后可重新运行脚本制作新副本。建议通过原版更新后重建，不依赖修改后副本的自动更新功能。

## 手动更换图标

脚本不会替换图标，也不会重启 Dock。图标是可选的，不影响重建。完成时会显示脚本旁的 `wechat_icons` 文件夹路径。

1. 在“应用程序”中右键点击 `WeChat2.app` 图标，选择“显示简介”。
2. 将 `wechat_icons` 文件夹中的图标拖到“显示简介”窗口左上角的小图标上，覆盖原图标。

每次重建后可能需要重新设置图标。请通过 Finder 修改自定义图标，不要在签名后直接替换应用包内部资源。

## 检查范围

脚本提供中英文自身提示；系统命令的原始错误信息可能仍使用系统语言。语法检查及两种语言的取消流程已经验证；此次更新未执行实际重建。
